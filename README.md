# JiTP 

---

This is a simple Minecraft mod that allows low privileged players to use the tp command.
Of course, low privileged players cannot use all the functions of TP, they are only allowed to use some simple functions,
For example, teleporting to other players or designated locations. Advanced features such as target selectors are not allowed to be used.
Added a switch in the configuration, which immediately prohibits players from using the tp command when turned off.

---

# 叽TP

这是一个简单的Minecraft mod，允许低权限玩家使用tp命令。
当然，低权限玩家不能使用TP的所有功能，其只被允许使用一些简单的功能，
例如传送到其他玩家或指定位置。不允许使用目标选择器等高级功能。 
在配置中添加了一个开关，该开关在关闭时立即禁止玩家使用tp命令。
