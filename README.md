# JiTP | 叽TP

---
This is a simple Minecraft mod that allows low privileged players to use the tp command.
Of course, low privileged players cannot use all the functions of TP, they are only allowed to use some simple functions,
For example, teleporting to other players or designated locations.
---
这是一个简单的Minecraft mod，允许低权限玩家使用tp命令。
当然，低权限玩家不能使用TP的所有功能，其只被允许使用一些简单的功能，
例如传送到其他玩家或指定位置。
